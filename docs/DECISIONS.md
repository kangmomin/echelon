## 데이터 수치에 대해

`data/weapons`, `data/elements` 의 수치(관통력, 장갑, 사거리 등)는 **자리표시 초기값**이다. 실제 장비의 공개 제원을 참고한 대략치이며 M7 밸런싱 전까지 신뢰하지 않는다.

## 내보내기 주의

`data/*.json` 은 Godot 가 import 하지 않는 파일이다. 내보내기(Export) 프리셋을 만들 때 **Resources → Filters to export non-resource files** 에 `*.json` 을 넣어야 빌드에 포함된다.
