- Godot 4.7.2, 정적 타입 GDScript. 시뮬레이션(노드·Time 미사용, 10 Hz 고정 틱, 시드 결정론)과 표현 계층 분리.

- 데이터(확장 후): 엘리먼트 46종, 무기 46종, 중대·소대 템플릿 39종, 대형 14종, 편제표 2, 기본 편성 2, 지도 1, 시나리오 1.
- 테스트: **GUT 95개 통과**, 타입·안전성 경고 20종을 오류로 올린 정적 검사 **0건**, 헤드리스 스모크(샌드박스·스커미시) 통과.
- 실행 흐름: 메뉴 → 편성 → 배치 → 전투 → 사후 검토(AAR). 샌드박스, AI 대 AI 관전(`--ai-vs-ai`), 헤드리스 AAR JSON 도구 포함.

## 성능 (M7 측정, 헤드리스, 이 세션 환경 2코어)

`tools/profile_sim.gd --extra=5`: 엘리먼트 297개·제대 95개, AI 대 AI 교전 1,500틱.

| 항목 | 최적화 전 | 후 |
| --- | --- | --- |
| 평균 틱 시간 | 17.5 ms | 15.4 ms |
| 최대 틱 시간 | 74 ms | 51 ms |
| 이동 / 탐지 / 통신 / 사격 | 11.1 / 3.9 / 1.1 / 0.9 ms | 8.9 / 4.0 / 1.1 / 1.0 ms |

1배속(10틱/초)이면 시뮬이 CPU 시간의 약 15%를 쓴다. 틱이 도는 프레임은 15 ms 안팎이 추가되므로 **300개 규모에서 60 fps 를 꾸준히 지키지는 못한다**(틱 프레임에서 순간 하락, 4배속에서 뚜렷). 남은 비용 대부분은 GDScript 루프(엘리먼트 이동, LOS 표본)이며, 다음 단계는 (1) 이동·LOS·경로 단순화를 GDExtension(C++)으로 옮기기, (2) 시뮬을 작업 스레드에서 돌리고 표현은 스냅샷을 읽기 중 하나다. 렌더링 프레임률은 GPU 가 없는 이 환경에서 잴 수 없었다.

## 밸런스 1차와 남은 문제

자세한 표는 `docs/PLAYTEST.md`.

- M6 직후 러시아가 6판 모두 5분 안에 붕괴(손실 약 3 : 51). 미군 차량 cost 상향, 원거리 명중 감쇠, AI 전력비 판단, 러 편성 보강, 배치 깊이 조정으로 **미 6 : 러 2**까지 맞췄다.
- **가장 큰 문제는 판의 길이**다. 40분 설계에서 실제 판은 7분 안팎, 정면 조우전 한 번으로 전투력 붕괴가 난다. 증원(T+10분)이 들어오기도 전이다. 지휘 지연(18~20초)이 의미를 가지려면 교전이 더 길게 펼쳐져야 한다.
- 지도·거점 배치가 비대칭이다(교차로 FOX 가 러시아 쪽에 치우쳐 FOX 를 잡으면 러시아 후방이 사거리 안).

## 하지 않은 것 / 알려진 한계

- 사람 플레이테스트 5판: 이 세션은 사람이 조작할 수 없어 AI 대 AI 기록과 양식만 남겼다. "제대 지휘가 재미있는가"의 판정은 양식을 채운 뒤에 가능하다.
- (선택 항목) 명령 로그 리플레이 세이브: 결정론(시드·명령)과 명령 객체 직렬화는 준비돼 있으나 저장·재생 기능은 만들지 않았다.
- 보병의 건물 점령, 공병, 연료, 반포병, 지도·시나리오 추가는 PLAN 13.2(범위 밖) 그대로.
- 엘리먼트 3D 표현은 장비별 저폴리 모델(차체 + 표적을 따라 도는 포탑, 경사 추종, 격파 시 포탑 들림)이다. 판독은 여전히 NATO 풍 부호가 주로 맡는다.
- 전투 효과(포구 섬광·포연, 예광탄·미사일 연기 꼬리, 명중 불티, 격파 화염과 불타는 잔해, 포탄 흙기둥·먼지 고리·포탄 자국, 연막 차장)는 표현 계층의 자체 입자 시스템(MultiMesh 2개)으로 그린다. 시뮬 해시는 그대로다. 웹은 입자 상한을 낮추고 섬광 조명을 끈다.

## 다음 단계 제안 (우선순위순)

1. **판 길이 조정 실험**: FOX 를 지도 중앙으로 옮기고, 붕괴 판정을 "지도 위 부대 기준 25%"로 바꾼 뒤 AI 대 AI 8판으로 길이·승률을 다시 잰다(`tools/headless_battle.gd`, 판당 30~60초).
2. **사람 플레이테스트 5판**: `docs/PLAYTEST.md` 양식. 핵심 지표는 "중대 단위로 지휘한 비율"과 "지연 때문에 계획을 바꾼 순간".
3. **AI 개선**: 첫 5분 정찰 우선, 확보 거점 방어 후 화력 준비, 지휘소 보호.
4. **성능**: 이동·LOS 를 GDExtension 으로.
5. 지휘 체계 회복 수단(재편 명령, 지휘소 이동) — 현재는 두절·승계 공백이 일방적인 벌칙이다.
